# CampusGuard - KNUST Campus Safety System

Web-based emergency alert system for KNUST students. React + Tailwind CSS + JSON Server.

## Quick Start

```bash
npm install
npm run dev
```

Runs React on http://localhost:3000 and JSON Server on http://localhost:3001.

## Features

- One-Tap SOS with GPS
- Safe Walk live tracking
- Incident reporting
- Alert broadcasting
- Guardian management
- 3 roles: Student, Security, Guardian
